# Driver Evaluation System

## Overview
This project is a professional login page developed with the Lovable framework. It provides a seamless user experience alongside robust functionality.

## Architecture
The login page is structured with a clear and intuitive architecture.
- **Frontend**: Built using HTML, CSS, and JavaScript to ensure compatibility across different devices.
- **Backend**: Integrated with Node.js for handling login requests and managing user sessions.

## ✨ Key Features

### 1. **Multi-Type Assessment System**
Supports three distinct assessment types:
- **In-Cab Assessment** - Real-world driving evaluation focusing on practical skills
- **Interview Test** - Theoretical knowledge and psychotechnical evaluation
- **Initial Practical Test** - Foundational capability assessment

### 2. **Professional Authentication**
- Hardcoded credential-based login system (Demo)
- User session management via localStorage
- Pre-filled demo credentials: `admin@tristar.com` / `tristar123`

### 3. **Comprehensive Dashboard**
- Real-time statistics display with performance metrics
- Multi-segment donut chart for KPI visualization (Skill, Knowledge, Awareness)
- Driver assessment tiles with interactive navigation
- Quick-access cards for each assessment type

### 4. **Data Management**
- Driver database with persistent localStorage storage
- Support for creating, reading, updating, and deleting driver records
- Sample data initialization for demo purposes
- Automatic calculation of overall scores and status

### 5. **Advanced Visualizations**
- Circular progress indicators for individual metrics
- Multi-segment donut charts for aggregate KPI analysis
- Assessment distribution pie charts
- Monthly trend bar charts
- Location-based company distribution analytics

### 6. **Signature Capture**
- Canvas-based signature drawing interface
- Touch and mouse support
- High-resolution signature export

### 7. **Responsive Design**
- Mobile-first approach with Tailwind CSS
- Glassmorphism UI effects with backdrop blur
- Smooth animations and transitions using Framer Motion
- Floating background elements for visual depth

---
## Technology Stack
- **Frontend**: HTML5, CSS3, Bootstrap, JavaScript
- **Backend**: Node.js, Express
- **Database**: Firebase

## Setup Instructions
1. **Clone the Repository**: 
   ```bash
   git clone https://github.com/Dragocodich/Professionaltristarloginpage.git
   cd Professionaltristarloginpage
   ```

2. **Install Dependencies**: 
   ```bash
   npm install
   ```

3. **Run the Application**: 
   ```bash
   npm start
   ```

4. **Access the Application**: Open your browser and navigate to `http://localhost:3000`
